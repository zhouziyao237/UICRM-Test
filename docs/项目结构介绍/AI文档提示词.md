## 语言风格指南 🎨

### 幽默版写作风格

1. **使用生活化类比**：将技术概念与日常生活中的事物进行类比，使抽象概念具体化
2. **添加趣味性吐槽**：在代码示例中加入轻松幽默的注释，缓解技术学习的枯燥感
3. **使用形象化比喻**：用生动的比喻来解释技术原理，如"变形金刚"、"万能餐具"等
4. **采用对话式语气**：模拟与读者的对话，增加亲切感和互动性
5. **使用表情符号**：适当使用表情符号增加文档的趣味性和可读性

### 专业版写作风格

1. **使用准确术语**：使用行业标准术语，确保技术表达的准确性
2. **结构化描述**：采用"问题-分析-解决方案"的结构化写作方式
3. **提供技术细节**：深入解释技术原理和实现机制
4. **引用实际案例**：结合项目中的真实代码示例进行说明
5. **保持客观中性**：使用客观、中性的语言进行技术描述

### 通用写作规范

1. **代码格式统一**：所有代码示例使用统一的代码块格式
2. **文件路径标准**：使用标准的文件路径表示方法
3. **示例引用规范**：引用项目中的实际文件时使用完整路径
4. **层次结构清晰**：使用清晰的标题层级和编号系统
5. **语言简洁明了**：避免冗余表达，保持语言简洁有力
