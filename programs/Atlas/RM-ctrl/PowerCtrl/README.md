# 卡尔曼滤波 + LQR 底盘控制算法（MATLAB 面向对象版）
一份可直接跑仿真、结构清晰、适合RoboMaster/机器人控制学习的 **LQR+Kalman** 控制框架。

---

## 1. 项目介绍
本项目实现一套完整的**麦轮底盘闭环控制**：
- **LQR**：做速度/转速跟踪，保证控制平滑、跟踪精度高
- **卡尔曼滤波(KF)**：对功率进行**状态估计 + 未来100ms预测**
- **功率缓冲管理**：按赛季规则仿真功率缓冲消耗、预警、分级限速
- **面向对象(OOP)**：模块化、易读、易移植到嵌入式(C++)

整体流程：
```
速度指令 → 功率预警限速 → 麦轮逆解 → LQR控制 → 电机输出
                                          ↓
电流/功率观测 → 卡尔曼滤波 → 功率预测 → 缓冲与限速决策
```

## 5. 核心类说明

### 5.1 KFPowerEstimator.m —— 卡尔曼功率估计
- 状态：`[功率, 功率变化率]`
- 功能：
  - 实时估计功率
  - 预测未来 **100ms** 功率
- 接口：
  - `obj = KFPowerEstimator(DT)`
  - `update(P_meas)` 输入观测功率，更新估计
  - `P_est` 估计功率
  - `P_pred` 预测功率

---

### 5.2 SeasonRuleManager.m —— 赛季与功率管理
- 支持赛季：`'2025'` / `'2026'`
- 功能：
  - 功率上限、缓冲上限、结算周期
  - 缓冲能量消耗/恢复
  - 三级预警 + 分级速度缩放
- 关键参数：
  - `P_LIMIT_BLOOD` / `P_LIMIT_POWER`
  - `Z_MAX` 缓冲上限
  - `SettlePeriod` 裁判结算周期

---

### 5.3 ChassisController.m —— 底盘控制核心
- 集成：
  - LQR 控制器设计
  - 麦轮逆解
  - 卡尔曼估计
  - 功率预警与限速
- 接口：
  - `obj = ChassisController(DT, season_type, P_limit_type)`
  - `control(Vx, Vy, Vturn, t)` 一帧控制
  - `reset()` 重置状态

## 7. 常见问题与修改指南

### 7.1 想让缓冲真正被消耗（紫线掉下去）
- 把 `main.m` 里速度给大：
  ```matlab
  Vx_ref(k) = 10*(t-1); 
  ```
- 或临时关闭限速：
  ```matlab
  obj.speed_scale = 1.0; 
  ```

### 7.2 调整 LQR 效果
在 `ChassisController.m > init_lqr`：
```matlab
Q_lqr = diag([300,300,300,300]); % 跟踪权重（调大更狠）
R_lqr = diag([1,1,1,1]);         % 控制惩罚（调大更柔）
```

### 7.3 调整卡尔曼滤波平滑度
在 `KFPowerEstimator.m` 构造函数：
```matlab
Q = diag([0.1, 0.01]); % 过程噪声（调大更信任模型）
R = 1.0;               % 观测噪声（调大更滤波）
```

## 8. 报错常见原因
- **类没有公共属性 xxx**：属性权限没放开（本版已全部修复）
- **未找到类**：所有文件必须在**同一目录**
- **lqr 函数报错**：确保 A、B 维度正确（本版为 4 电机状态）

## 9. 移植到嵌入式（STM32 / C++）建议
- 类 → 结构体 + 函数
- 矩阵运算 → CMSIS-DSP 或手写简单矩阵
- DT 用系统时钟周期
- 只保留核心：
  - LQR 反馈 `u = -K*x`
  - 卡尔曼预测+更新
  - 缓冲计算、限速
